## 4. 选择

```python
df["a"]                       # 一列 → Series
df[["a", "b"]]                # 多列 → DataFrame
df.filter(like="amount")      # 列名含关键词
df.select_dtypes("number")    # 按类型选列

df.loc[行标签, 列标签]         # 按标签，含结尾
df.iloc[行号, 列号]            # 按位置，不含结尾
df.loc["2024-03-05"]          # 时间索引切片
df.loc["2024-03-05":"2024-03-06"]
df.at[0, "amount"]            # 单个格子（标签）
df.iat[0, 5]                  # 单个格子（位置）

df[df["amount"] > 100]                                  # 布尔筛选
df[(df["amount"] > 100) & (df["city"] == "北京")]        # 与
df[(df["city"] == "北京") | (df["city"] == "上海")]      # 或
df[~df["city"].isin(["北京"])]                           # 非
df[df["city"].isin(["北京", "上海"])]
df[df["amount"].between(100, 500)]
df[df["name"].str.contains("科技", na=False)]

df.query("amount > 500 and city == '北京'")               # 字符串条件
df.query("amount > @threshold")                          # 引用外部变量
df.query("`金额` > 500")                                  # 中文列名加反引号
```

> 多个条件：用 `& | ~`，每个条件加括号；不要用 `and` / `or`。

## 14. 常见报错 → 原因与解法

| 报错 | 原因 | 解法 |
| --- | --- | --- |
| `ChainedAssignmentError` / `SettingWithCopyWarning` | 链式赋值 `df[cond]["c"] = v` | 改 `df.loc[cond, "c"] = v`；或先 `.copy()` |
| `KeyError: 'xxx'` | 列名/索引不存在 | `print(df.columns.tolist())`；注意 `loc[1]` 是标签不是位置 |
| `ValueError: The truth value of a Series is ambiguous` | 用了 `and` / `or` | 用 `&` / `|` 并加括号 |
| `AttributeError: 'DataFrame' object has no attribute 'applymap'` | pandas 3 移除了 | 用 `df.map(func)` |
| `Invalid frequency: M` | 频率字符串变了 | 用 `ME` / `QE` |
| `NDFrame.fillna() got an unexpected keyword argument 'method'` | `method=` 被移除 | 用 `ffill()` / `bfill()` |
| `ArrowInvalid: invalid escape sequence: \u` | pandas 3 正则引擎不认 `\u` | 直接写字符，如 `"[\u4e00-\u9fff]"`（不要 `r`） |
| `UnicodeDecodeError` | 编码不对 | `encoding="gbk"` 或 `"utf-8-sig"` |
| 多出 `Unnamed: 0` 列 | 写 CSV 时没加 `index=False` | 写出时加 `index=False` |
| `merge` 后行数暴涨 | 键在多侧不唯一（多对多） | 先 `validate="one_to_one"` 检查，或先聚合再 merge |
| `resample` 报索引错 | 索引不是 DatetimeIndex 或没排序 | `set_index("ts").sort_index()` |
| `Cannot mask with non-boolean array containing NA` | 可空布尔里有 `NA` | `.fillna(False)` 或 `.astype(bool)` |

## 15. 一句话原则

1. **先看再动手**：`info()` + `value_counts()` + `describe()`。
2. **标签对齐是默认行为**，对不上就是 NaN，不是 bug。
3. **取数用 `loc` / `iloc`**，不要用裸 `df[...]` 取行。
4. **能向量化就不写循环**。
5. **每一步清洗都记账**：删了多少、为什么删。
6. **中间结果存 Parquet**，交付给人看再导 CSV / Excel。
