# Markdown 基本语法速查

## 标题

``` md
# 一级
## 二级
### 三级
```

## 强调

-   **加粗**
-   *斜体*
-   ***加粗斜体***
-   ~~删除线~~

## 列表

``` md
- 无序
1. 有序
- [ ] 任务
- [x] 完成
```

## 引用

``` md
> 引用内容
```

## 代码

行内：`code`

```` md
```python
print("Hello")
```
````

## 分割线

``` md
---
```

## 链接

``` md
[名称](https://example.com)
```

## 图片

``` md
![说明](image.png)
```

## 表格

``` md
| A | B |
|---|---|
| 1 | 2 |
```

## 数学公式

行内：`$E=mc^2$`

块级：

``` md
$$
x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}
$$
```

## 转义

``` md
\* \# \`
```
